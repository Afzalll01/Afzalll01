# 🌟 Featured Projects

## 🗺️ Bharat Bhumi — Land Governance Platform

> **A GIS-based Land Stack for unified and transparent land governance.**

Bharat Bhumi integrates land parcel information into a unified platform using **GIS, spatial databases, role-based access control, and analytics**.

### Key Features

* 🗺️ Interactive GIS-based parcel explorer
* 📍 Parcel-centric land information
* 🔐 JWT authentication & role-based access control
* 👤 Citizen property management
* 🏛️ Officer governance workspace
* ⚙️ Administrative governance dashboard
* 🔎 Property and parcel search
* 📊 Analytics & governance insights
* 🗄️ PostgreSQL + PostGIS spatial database

### Tech Stack

`React` `TypeScript` `Leaflet` `OpenStreetMap` `Spring Boot` `Java` `PostgreSQL` `PostGIS` `JWT`

## 🥘 FridgeChef — AI Recipe Recommendation System

> **An AI-powered application that detects ingredients from fridge images and recommends recipes.**

FridgeChef uses **YOLOv8 Computer Vision** to identify ingredients from uploaded images and combines the detected ingredients with a recipe system to provide relevant meal suggestions.

### Key Features

* 📸 AI-based ingredient detection
* 🤖 YOLOv8 Computer Vision model
* 🥕 Manual ingredient selection
* 🔍 Ingredient search & autocomplete
* 🍳 Recipe recommendations
* ❤️ Favorites
* 🕘 Search history
* 🌙 Dark mode

### Tech Stack

`YOLOv8` `Python` `Flask` `JavaScript` `HTML` `CSS` `Bootstrap` `SQLite`
